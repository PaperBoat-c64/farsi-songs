# farsi-songs
# خداحافظ — 波斯语歌曲逐词对齐学习页

## English

This is an interactive, word-by-word aligned lyric study page for the Persian song **"Khodāhāfez" (خداحافظ / "Goodbye")**. Built for Chinese-speaking Persian learners, it presents each line of the song in three parallel rows:

- **Original text** — Persian script (RTL, Arabic alphabet), color-coded tokens
- **Romanization** — UniPers transliteration for pronunciation reference
- **Translation** — natural, fluent Chinese rendered to a "信·达·雅" (faithfulness, clarity, elegance) standard

Each colored word token is interactive:

- **Hover / long-press** → a quick tooltip shows the word, pronunciation, part of speech, and contextual meaning
- **Click / tap** → a full dictionary card opens with lemma (root form), all meanings, examples, grammar notes, synonyms, and collocations where available

The page includes a collapsible **vocabulary table** (74 unique words with frequency counts), an **alignment summary** (27 lines, 139 semantic units, ~94% average alignment confidence), and supports full RTL layout, dark mode, and mobile responsive design. Its structure follows the song itself: **Verse 1 → Chorus → Verse 2 → Chorus**.

The song is a bittersweet farewell — after a lover leaves, the narrator bids goodbye to the moon and the mirror, with choked-back tears and a love that has "no home to return to."

## 中文

这是一个针对波斯语歌曲 **《خداحافظ》（Khodāhāfez /「再见」）** 的交互式逐词对齐歌词学习页面。它面向中文母语的波斯语学习者，将每一行歌词以三行平行的形式呈现：

- **原文** — 波斯语阿拉伯字母书写（RTL 从右向左），按语义单位着色
- **罗马字转写** — 采用 UniPers 系统，方便对照发音
- **中文翻译** — 以「信·达·雅」为标准的地道中文译文

每个彩色词块都支持交互：

- **悬停 / 长按** → 弹出快速提示，显示单词、发音、词性与语境含义
- **点击 / 轻点** → 打开完整词典卡片，包含词根（lemma）、全部义项、例句、语法说明、近义词与常用搭配（如有）

页面还包含可折叠的**词汇表**（74 个词条，附频次统计）与**对齐摘要**（27 行、139 个语义单元、平均对齐置信度约 94%），并完整支持 RTL 排版、深色模式与移动端响应式布局。整体结构遵循歌曲本身：**Verse 1 → Chorus → Verse 2 → Chorus**。

这首歌是一首略带苦涩的告别曲：恋人离去后，歌者向月亮与镜子道别，胸中哽咽，一段「无家可归」的爱也随之迷失在对方心里。
